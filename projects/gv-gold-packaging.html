Три формата.
Один бренд.

Александр Курбатов Дизайн упаковки

01 / НОВОГОДНИЙ ПОДАРОК

Праздничная упаковка.

Коробка для новогоднего подарка объединяет зимнюю иллюстрацию, светлые поверхности с тонким рисунком и яркие оранжевые ленты.

02 / УНИВЕРСАЛЬНЫЙ ПАКЕТ

Фирменный пакет
для разных поводов.

Чёрная матовая поверхность, золотистая графика рельефа и фирменный знак создают лаконичную упаковку, которую можно использовать независимо от праздничной темы.

03 / НАГРАДА

Упаковка для
значимого предмета.

Отдельное решение создано для награды с керном золотосодержащей породы. Чёрная раскрывающаяся коробка поддерживает строгий характер предмета и показывает награду после открытия.
