# ИНСИТИ — обязательный источник логотипа

По прямому указанию Александра от 04.11.2026 старый логотип исключён из рабочих исходников.

## Единственный эталон
- Файл: `assets/incity-logo-approved.svg` в этой папке (`incity-draft/assets/incity-logo-approved.svg` от корня репозитория).
- Источник эталона: актуальный вектор из раздела «Стало» сайта ИНСИТИ, совпадающий с логотипом первого экрана.
- Всегда сначала читать этот файл. Не выбирать логотип по похожему имени файла, дате или старым ответам.
- `Logo.ai`, `01-Logo.ai`, старый `INCITY_logo_original.svg`, ранние PDF/SVG/ZIP и предыдущие варианты не являются источником утверждённого логотипа.
- Если эталон недоступен, восстановить именно этот путь из репозитория; не подставлять старый логотип.

## Сохранение оригинала
Не перерисовывать, не генерировать заново и не заменять буквы шрифтом. Сохранять точные контуры крыши, основания, стоек, названия и дескриптора из эталона.
Для разрешённых вертикальных компоновок, модульных схем и монохромных вариантов использовать копии исходных путей. Допустимы только согласованные размещение, равномерный масштаб групп и цвета.
Перед публикацией сравнивать `d` и исходные `transform` всех путей с эталоном, включая чёрно-белые варианты.

## Текущая модульная система
- x = половина высоты буквы «Н» из эталона; высота «Н» = 2x.
- Охранное поле = 2x со всех сторон, включая чёрные и белые исполнения.
- Выносные направляющие должны показывать точные границы каждого измерения.
- Старое изображение в историческом сравнении «Было» не использовать как мастер.
